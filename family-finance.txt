[9] USER — Cập nhật tài liệu và đẩy lên GitHub
----------------------------------------------------
User: "cập nhật lại các file cần, tổng hợp xong thì đẩy lên github"

Dự án đã được mở rộng đáng kể từ lần tạo tài liệu trước.
Claude phát hiện các thay đổi lớn:

THAY ĐỔI DATABASE:
- SQLite → PostgreSQL
- DATABASE_URL qua biến môi trường

MODELS MỚI TRONG SCHEMA:
- SubFund / SubFundMember      — Quỹ phụ gia đình
- WalletPocket / PocketEntry   — Ngăn ví (envelope budgeting)
- ExchangeRate                 — Tỷ giá ngoại tệ
- SavingsGoal / SavingsContribution / SavingsWithdrawalRequest/Approval — Tiết kiệm
- PlanItem / PlanCompletion    — Dự thu / Dự chi
- Hui / HuiRound               — Hụi (rotating savings club)
- RecipientLabel               — Nhãn người nhận
- MonthlyBudget / MonthlyBudgetItem — Ngân sách tháng
- WeeklyBudget                 — Ngân sách tuần

THAY ĐỔI MODELS HIỆN CÓ:
- User: thêm isAppAdmin, nhiều ví cá nhân (personalWallets[])
- Wallet: thêm currency, name, subFundId, pockets[], closedAt
- Transaction: thêm pocketId, transferGroupId, recipientLabelId
- Category: thêm keywords, userId (danh mục tuỳ chỉnh theo user)
- Debt: thêm lenderUserId, borrowerUserId, walletTransactionId

ROUTES MỚI:
budgets, exchangeRates, hui, monthlyBudgets, planItems,
pockets, recipients, savings, subFunds, transfers, wallets, admin

TÍNH NĂNG BẢO MẬT:
- tokenVersion: thu hồi phiên đăng nhập không cần blacklist
- isAppAdmin: admin toàn hệ thống (tách biệt admin gia đình)
- Socket.IO middleware xác thực tokenVersion

UX CẢI TIẾN:
- Show/hide mật khẩu trong form đăng nhập
- Thông báo "phiên đăng nhập hết hạn" thay vì lỗi 401 im lặng
- VITE_API_URL để cấu hình backend URL khi deploy
